# Support for Jelto contracts

Start with the [README](README.md) and [Jelto documentation](https://jelto.io/docs/). For local
builds and tests, see [CONTRIBUTING.md](CONTRIBUTING.md); maintainers publish using
[RELEASING.md](RELEASING.md).

## Public questions and reports

Search [the issue tracker](https://github.com/usejelto/contracts/issues), then open a bug report, feature request
or blank issue for a question or documentation correction. Include the package
version or commit, platform, expected result and a small reproducible example.
Documentation issues are welcome here even when the guide is maintained elsewhere.

Use synthetic data and redact diagnostics. Never post API keys, session tokens,
customer payloads, IP addresses or other people's personal information. Debug
payload logging is for local diagnosis, not an invitation to attach raw traffic.

## Private help

- Security or privacy vulnerabilities: follow [SECURITY.md](SECURITY.md).
- Conduct reports: follow [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
- Hosted-account, billing or other private support: email Taha Bozdemir at
  [taha@jelto.io](mailto:taha@jelto.io).

Support and reviews are best effort, with no guaranteed turnaround. A feature
request is a proposal, not a commitment to deliver it. Until this component's
public repository is available, use the email address above for questions and
reports; the GitHub links are its intended publication destinations.
